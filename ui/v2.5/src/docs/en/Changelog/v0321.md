### ⚠️ Notable Changes

* PostgreSQL support is experimental. It has to be chosen before first setup, with the `STASH_DATABASE` environment variable; the setup wizard can't switch to it. The PostgreSQL page in the manual has the requirements and steps.
* Builds no longer check stashapp/stash for updates, which offered older versions with a different database. A build only checks for updates if it's built with `UPDATE_REPO` set.

### ✨ New Features

* Administrators can now add, edit, lock, unlock and delete accounts, and set their passwords, under Settings > Security > Accounts.
* Added a PostgreSQL page to the manual.

### 🐛 Bug fixes

* PostgreSQL: the Images page failed to open, and sorting scenes, images or audio by path or title, or scenes by similarity, returned an error. Many filters also failed.
* PostgreSQL: a list with an item that has several files, such as a merged scene, could fail, repeat the item, or give totals that changed with the sort.
* Filtering scenes by a markers filter matched every scene.
* Filtering galleries by a folder's parent or gallery count returned a database error.
* PostgreSQL: the database password was shown on the About and settings pages, including to anyone before signing in. It's now hidden.
* PostgreSQL: changes were allowed while a database upgrade was still needed.
* Requests made before setup crashed with "Internal system error" instead of saying the database isn't ready.
* A batch update of studios from a stash-box crashed when a result had no matching local studio.
* Editing only an account's notes could sign it out.
* Deleting an image in a zip gallery with "Delete file" left it in the zip, so a rescan added it back. It's now removed from the zip. With a trash folder set, the original zip goes to the trash.
* The "excludes" and "is not" text filters left out items where that field was empty.

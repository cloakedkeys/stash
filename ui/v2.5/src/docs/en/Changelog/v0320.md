### ⚠️ Notable Changes

* The security tripwire has been replaced. If no credentials are configured, requests from public IP addresses are now rejected with a 403 error instead of shutting down stash. Public IP ranges can be allowed using the new `public_whitelist` config field (CIDR format, e.g. `192.168.1.0/24`), and non-local proxies can be configured with the new `trusted_proxies` field. The `dangerous_allow_public_without_auth` and `security_tripwire_accessed_from_public_internet` config fields have been removed. ([#7085](https://github.com/stashapp/stash/pull/7085))
* Marker preview generation now honours the marker's end time. The previous hardcoded 20 second limit is now an optional `Max marker preview duration` setting (default `0` - no limit). ([#6855](https://github.com/stashapp/stash/pull/6855))
* The UI has been upgraded to React 18. UI plugins that depend on React internals may need to be updated. ([#7276](https://github.com/stashapp/stash/pull/7276))
* The Clean task has been replaced by two tasks. `Verify files` marks files and folders that are no longer on disk as missing instead of deleting them, and `Purge missing` removes missing items from the database. A file that reappears is un-marked on the next scan. ([#7126](https://github.com/stashapp/stash/pull/7126))
* Video perceptual hashes are now calculated differently for videos of 2.5 minutes or less. The existing phashes for these videos are deleted when upgrading; run the Generate task with `Video perceptual hashes` to regenerate them. ([#7225](https://github.com/stashapp/stash/pull/7225))
* Group aliases are now a list. Each group's existing aliases text is migrated as a single alias, so aliases previously entered as a comma-separated list need to be split manually. ([#6951](https://github.com/stashapp/stash/pull/6951))

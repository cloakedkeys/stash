### ⚠️ Notable Changes

* PostgreSQL 18 is now the version Stash is tested with. The Docker Compose example on the PostgreSQL page of the manual uses it.
* PostgreSQL no longer needs the `plperl` extension. Regex filters now give the same results as on SQLite. Plugins that call `regex_match` through raw SQL need to use PostgreSQL's regular expression syntax. A backup made before this version can only be restored on a server that has `plperl`.
